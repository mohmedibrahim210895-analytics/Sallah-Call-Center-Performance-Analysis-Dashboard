# 📞 Call Center Operations Dashboard - Power BI

## 🚀 Overview
This project presents an interactive call center dashboard built using Power BI to analyze operational performance across multiple projects and agents.

The dashboard focuses on monitoring call volume, service efficiency, and agent performance to support better workforce planning and decision-making.

![Overview](OverView.jpg)
![Team Analysis](Team Analysis.jpg)

## 📊 Key Features
- Multi-project performance tracking (Project A, B, C)
- Agent-level performance analysis
- Call volume vs forecast comparison
- Service level and accuracy monitoring
- Abandon rate and response time tracking
- Interactive filters (Agent, Month)

## 📈 KPIs
- Total Offered Calls: 1.74M  
- Total Handled Calls: 1.72M  
- Calls Within Threshold: 1.59M  
- Abandon Rate: 1.32%  
- Service Level: 91%  
- Accuracy: 72%  
- ASA (Average Speed of Answer): 9 sec  

## 🔍 Key Insights
- Project B handles the highest call volume but shows lower efficiency compared to other projects.  
- Project C achieves the highest accuracy despite lower call volume, indicating better process control.  
- A noticeable gap between forecasted and actual calls suggests opportunities for improving demand planning.  
- Higher abandon rates are associated with peak call periods, highlighting capacity constraints.  
- Top-performing agents consistently maintain high service levels above 95%, while others show performance gaps.  
- ASA (response time) directly impacts both service level and customer experience.
