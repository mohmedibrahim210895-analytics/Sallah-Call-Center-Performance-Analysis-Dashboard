# 📊 Call Center Performance Analysis Dashboard

## 📌 Overview
This project presents an interactive dashboard built using Power BI to analyze call center performance across multiple teams and projects.

## 🎯 Objectives
- Monitor call center KPIs
- Evaluate agent and team performance
- Identify trends and operational gaps
- Support data-driven decision-making

## 📊 Key Metrics
- Total Offered Calls: 1.7M+
- Total Handled Calls: 1.72M+
- Calls Within Threshold: 1.59M+
- Abandon Rate: 1.32%

## 📈 Features
- Team performance analysis (Agent-level insights)
- Monthly trend analysis
- Call handling vs abandoned calls comparison
- KPI tracking dashboard
- Interactive filters (Agent, Month)

## 🛠 Tools Used
- Power BI
- Power Query (Data Cleaning)
- DAX (Calculated Measures)
